# 🎓 College Admissions Portal

A full-stack **College Admissions Portal** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. This application streamlines the college admission process by allowing students to apply online and enabling administrators to manage applications efficiently.

---

## ✨ Features

### 👨‍🎓 Student
- Register and Login securely
- Fill out the online admission form
- Upload required documents
- Track application status (Pending, Approved, Rejected)
- View submitted application details

### 👨‍💼 Admin
- Secure Admin Login
- View all student applications
- Search and filter applications
- Approve or Reject applications
- Manage admission records

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/college-admissions-portal.git
```

### 2. Navigate to the Project

```bash
cd college-admissions-portal
```

### 3. Install Backend Dependencies

```bash
cd server
npm install
```

### 4. Install Frontend Dependencies

```bash
cd ../client
npm install
```

### 5. Configure Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### 6. Start the Backend

```bash
cd server
npm start
```

### 7. Start the Frontend

```bash
cd client
npm start
```
